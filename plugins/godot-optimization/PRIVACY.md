# Privacy policy: godot-optimization

This plugin collects, stores and sends no data.

- It contains one skill (written instructions for Claude) and four GDScript files that you copy into your own Godot
  project and run yourself.
- It has no MCP servers, no hooks, no network calls and no telemetry.
- Nothing it contains reads personal data, and nothing is retained by the author.

Questions: open an issue at https://github.com/dmytriyvihrov-stack/godot-optimization/issues
